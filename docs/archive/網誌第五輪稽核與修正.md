## 已修正問題

| 問題 | 修正結果 |
| --- | --- |
| 舊文章可能套用新文章模板，覆蓋原有 metadata | 五份文章 SKILL 區分新增與修訂；修訂採局部修改，保留未知欄位、既有網址與原始發表日期。 |
| 純排版或圖片轉檔也可能改動更新日期 | 明定這些操作保留 updated；實質內容修改使用可靠的台北時間，更新單一欄位，並檢查修改時間不早於發表時間。明確更正錯誤日期仍可依使用者要求執行。 |
| 正文修改後摘要、結構化資料可能失去對應 | SKILL 要求核對手寫 description／excerpt；JSON-LD 統一由主題產生，核對標題、網址、日期及代表圖片。 |

| 工作知識共用卡被當成文章代表圖片 | 四篇使用共用 work-knowledge-card.svg 的文章省略 JSON-LD image，畫面封面維持原樣；不全面排除其他 SVG。 |
| 檢查器可能放過資料與頁面不一致，或遇到異常資料就崩潰 | 加入 canonical 對應生成路徑、標題、發表時間、語言、作者／發佈者及 Microdata 身分比對，並處理非字串標題與無效識別碼。 |
| 手冊混合本站慣例與外部規範 | 修正 CollectionPage 範例、標籤正規化說明，分清 Google 建議與本站檢查要求，補充 SearchAction 與已退役搜尋框功能的差異。 |

## 外部規範核對

Google Article 文件未列必要屬性，建議依內容提供適用欄位；本站要求的欄位不可寫成 Google 一律必填。[Google Article 文件](https://developers.google.com/search/docs/appearance/structured-data/article)

Google 支援多個結構化資料項目；本站單一 JSON-LD 物件及 self-canonical 的限制屬於本地設計與檢查慣例。[Google 結構化資料政策](https://developers.google.com/search/docs/appearance/structured-data/sd-policies)

publisher 可以是 Person 或 Organization，本網誌使用個人作者符合該屬性的定義。[Schema.org publisher](https://schema.org/publisher)

Google 自 2024-11-21 起移除 sitelinks search box；這不等於 Schema.org SearchAction 語意失效，也不應宣稱加入它能恢復搜尋結果中的搜尋框。[Google 公告](https://developers.google.com/search/blog/2024/10/sitelinks-search-box)

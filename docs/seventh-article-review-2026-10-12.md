- 作者要求：依貼上的文字接續第七篇，完成後發布；推送後不再驗證，線上驗證由作者自行處理。

- 系列銜接：前六篇只增加第七篇的系列閱讀連結；正文、標題、日期及原網址保留。校驗清單補入新文章，同步系列 footer 的正文雜湊，公開文章數為 283。
- 發布前實際驗證：摘要檢查通過（27／86 字、單一 more 標記）；git diff --check 通過；完整 npm run verify 通過；生成頁面新標題、七個小標題與主要脈絡均存在；283 篇文章網址與 393 個 HTML 輸出檢查通過。
- 首輪回歸測試讀到舊的 navigation-index，找不到新增文章；先 build 更新索引後，重新執行完整 verify 通過，未改動測試或略過失敗。
- 發布方式：保存來源提交並推送 source，再將已驗證的 public 以 Hexo deploy 推送 main；使用既有發布倉庫與作者資訊。
- 下一步：依作者要求，推送後不查 GitHub Pages／Actions、不讀線上文章、不再跑驗證；線上驗證交由作者。

# 動線改善第 1 項：資料對照與實作約定

盤點日期：2026-09-14。執行 `node tools/navigation-inventory.js`，以實際 Hexo 載入後的公開文章及目前來源檔驗證；沒有執行部署或重寫網站介面。

## 實際資料

| 來源 | 數量與欄位 | 目前可開啟位置 | 後續用途 |
| --- | --- | --- | --- |
| Hexo 公開文章 | 246 篇；title、date、categories、tags、content、path | 原文章 URL | 搜尋主紀錄及發表事件 |
| `source/microblog.json` | 20 則；date、tag、content；全部沒有 id，沒有完全重複資料 | `/status/`，目前沒有逐筆錨點 | 獨立搜尋結果及紀錄日期事件 |
| `source/reading-desk.yml` | 11 組、15 題；題目 id、date、title、source、url、state、note | 15 題全部連到公開文章；草稿夾卡片目前沒有逐筆錨點 | 補充文章的搜尋文字、學習來源及加入日期 |

現有搜尋設定是 `field: post`、`content: true`、`search.xml`。前端解析後保留 title/content/url，搜尋中的分類與日期篩選還沒有所需資料；分類按鈕目前只用於空白搜尋時的最近文章。碎碎念另在自己的頁面搜尋，草稿夾按日期顯示題目。

## 統一紀錄格式（第 2 項的實作約定）

採版本化靜態索引，包含 `schemaVersion`、`records`。每筆至少保存：

- `id`：穩定識別，不使用目前列表位置或 Hexo 資料庫內部流水號。
- `kind`：主紀錄類型 article、microblog 或獨立 learning。
- `sources`：可有多個來源，文章被學習題目引用時保留兩種來源資格。
- `title`、`text`、`categories`、`tags`：顯示與搜尋資料；text 排除腳本、樣式、行號與模板裝飾。
- `url`：真實目標文章或紀錄頁；第 2 項不要宣稱尚未實作的錨點已可使用。
- `date`、`dateKind`：主日期與明確意義。
- `events`：保留發表、加入草稿夾等不同日期事件，供第 5 項使用。
- `learningItems`：已配對題目的原 id、note、source、state、addedDate，保留命中來源與學習線索。

文章的 code/pre 本身可能是合法學習資料，不能為排除樣式而刪掉真正程式碼文字。前端顯示任何來源文字均須轉義或用文字節點；對 HTML、搜尋字詞與目標網址分別處理。

## 穩定識別與連結

1. 文章：以站內 canonical path 為穩定鍵；沿用 Hexo 的公開路徑，不自行從標題拼網址。Hexo `post.path` 在自訂 permalink 時可能以 `/` 開頭，必須先正規化，避免產生 `//learning/...` 被誤當外站網址。
2. 碎碎念：第 2 項為既有項目一次性新增持久 `id`，之後改文字、插入或排序都保留。可在首次遷移時由日期與內容雜湊產生，寫入後不隨內容重算；衝突與缺失要明確檢查。只新增欄位，不改既有文字、日期、順序。後續新增紀錄的維護指引需一併補上 id 規則。
3. 學習題目：保留現有 `reading-topic-01` 等 id；驗證唯一性。題目名稱改動不影響 id。
4. 第 3 項才實作 `/status/#<id>` 與草稿夾紀錄定位：需要能自動顯示未載入或折疊的目標，不能只有 URL 而沒有對應元素。
5. 文章段落定位需在第 3 項驗證真實 DOM；不靠陣列序號宣稱跨改版永久穩定，目標消失時退回文章而非錯跳另一段。

## 去重與日期

- 學習題目指向既有公開文章時，合併為一筆文章搜尋結果，把題目的 title、note、source 等納入可搜尋資料；學習來源篩選仍應找得到這筆文章。
- 目前預期基本搜尋紀錄數為 246 + 20 = 266，15 個學習題目附屬於其中 15 篇文章。數量是本次基準，不作永久固定測試常數。
- 搜尋匹配學習附註時，命中摘要必須顯示該附註及來源，不能只呈現沒有命中字詞的文章片段。
- 文章 `date` 是發表日；microblog `date` 是該則紀錄日期；reading item `date` 是加入草稿夾日期。不能彼此覆蓋，也不能把發表日當事件實際發生日。
- 作者明確填寫的 `updated` 才可用作更新事件；不要把 Hexo 由檔案修改時間推導的 updated 當成作者當天改寫紀錄。
- 全部以 Asia/Taipei 處理。無效日期需報告，缺日期保留為未標日期，不能補今天。日期篩選若命中多種事件，結果仍只有一筆並標示命中的日期角色。
- 目前 `future: true`、`render_drafts: false`，沒有未公開或未來日期文章進入本次盤點。後续仍沿用網站實際公開集合，不擅自更改發布設定。

## 公開邊界與例外

- 文章從 Hexo 公開 locals 取資料，不能直接把 `_drafts`、docs、tmp 或任意檔案掃入公開索引。
- 目前 microblog.json 與 reading-desk.json 本就是公開來源；索引只使用其中供頁面呈現的紀錄欄位，不引入其他本機資料。
- 學習題目連結若將來失效或指向未公開文章，不讀取該文章補內容。先回報、排除這個未解析目標；不把連結不存在當作發布許可。
- 未來若有合法外站學習資料或無文章的題目，保留為獨立 learning 紀錄，落到可定位的草稿夾卡片；外連只接受允許的 HTTP(S) 協定，不能執行來源提供的指令或腳本 URL。
- 日曆目前由 `calendar.json` 計數、`calendar-posts.json` 列文章；草稿夾維持自己的新增計數。第 5 項增加跨来源列表，不悄悄改動既有熱力圖計數。

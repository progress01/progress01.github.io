# 資料與程式位置

以下路徑都相對於正式專案 `D:\myblog1988\blog-1988`。日常操作回到[網站維護更新手冊](../../網站維護更新手冊.md)。

## 自己維護內容時

| 位置 | 內容與維護方式 |
| --- | --- |
| `source/_posts/` | 正式文章。沿用歌曲推薦、閱讀影評、隨筆、實驗室等既有目錄；資料夾與網站公開分類不一定相同，不要為了對齊分類搬舊文章 |
| `source/_drafts/` | 未公開草稿；第一次建立草稿時才需要這個資料夾 |
| `source/images/` | 圖片原檔；名稱是文章連結的一部分，避免任意改名 |
| `source/microblog.json` | 碎碎念；新增優先使用 `record`，修改保留既有 ID |
| `source/life-index.json` | 「現在的我」的文字和連結 |
| `source/reading-desk.yml` | 公開草稿夾的學習題目與進度，不等同未公開草稿 |
| `source/photos/index.md` | 圖牆圖片卡片與連結 |
| `source/_data/profile-home.yml` | 舊 A 面三路徑選集，只保留給內部相容檢查，不會顯示在網站上；A 面首頁依文章的 `surfaces` 自動列出 |
| `source/_data/content-categories.yml` | 全站共用分類 |
| `source/_data/content-tags.yml` | 全站主標籤與歷史別名 |

## 修改功能時才需要

| 位置 | 用途 |
| --- | --- |
| `_config.yml` | Hexo 網站設定 |
| `themes/next/_config.yml` | 主題設定 |
| `themes/next/layout/`、`themes/next/source/` | 畫面模板、樣式、瀏覽器程式 |
| `source/_data/surface-navigation.yml` | A／B 面的選單與切換設定 |
| `source/index.md`、`source/profile/` 等頁面檔 | 功能頁入口，日常新增文章不需要修改 |
| `source/2022/`～`source/2026/` 等日期路徑 | 保留舊網址的相容頁，不是第二份文章，不能當雜檔移除 |
| `source/lib/` | 網站使用的第三方程式 |
| `scripts/` | Hexo 建置時載入的網站功能 |
| `tools/`、`tools/lib/`、`tools/tests/` | 維護指令、共用邏輯與測試；不需要記住全部指令 |
| `scaffolds/` | 新文章／草稿／頁面的範本 |
| `package.json`、`package-lock.json` | 指令與套件版本；升級時一起檢查 |
| `.github/` | GitHub 工作流程 |
| `sitemap-template.xml` | 網站地圖模板 |

## 工具產物與保留資料

| 位置 | 用途 |
| --- | --- |
| `public/` | 自動生成的網站，不能當作文章原稿編輯 |
| `.deploy_git/` | 發布工具工作目錄 |
| `node_modules/` | 安裝的套件；`.cache/` 也保存驗證／發布狀態與紀錄工具的本機備份，不是長期來源備份 |
| `db.json` | Hexo 快取 |
| `_multiconfig.yml` | 舊本機設定，預設 npm 指令不使用；保留供搬機比對 |
| `tmp/` | 過往一次性驗收資料，已排除 Git 日常追蹤 |
| `skill-song-blog-update-staging/` | 舊歌曲維護技能的暫存來源，日常手動更新不使用 |
| `.git/` | 原稿版本紀錄，交由 Git 管理 |

## 外層工作區

`D:\myblog1988` 只是一個容納專案與歷史資料的工作區，不是 Git 專案根目錄。

| 位置 | 身分 |
| --- | --- |
| `blog-1988/` | 唯一日常工作專案 |
| `歷史資料/執行日誌/` | 整理收納的本機日誌；有原路徑與 SHA256 清單 |
| `blog-migration-2026-10-08/` | 2026-10-08 搬機備份 |
| `cleanup-backup-20261013/` | 2026-10-13 清理時保存的資料 |
| `restore-validation-luna6-20261015/` | 舊還原演練副本，含獨立 Git 資料，不是目前工作專案 |
| `legacy-recommend-validation-20261017/` | 舊推薦功能驗證副本 |
| `.npm-cache/` | 套件下載快取 |
| `新電腦還原步驟.md` | 舊搬機說明，非日常維護入口 |

備份和演練副本保留原位置，讓還原說明與歷史證據仍可追溯；不要拿副本中的舊文章覆蓋正式專案。

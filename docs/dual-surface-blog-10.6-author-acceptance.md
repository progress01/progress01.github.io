## 這次改動會影響什麼

- **入口與導覽：** `/` 是工作與學習最新年份全年熱力圖，`/memory/` 是個人記憶庫與隨機探索，`/profile/` 保留 A 面相容入口，`/profile/articles/` 是完整文章庫。A contextual menu 為「工作與學習」和「全部文章」，`aria-current` 依實際路由切換；B 的導覽與搜尋不變。頁面以一般連結互相切換。右上切換鈕卡帶字母表示目的面（A 頁顯示 B、B 頁顯示 A），與 SIDE B／SIDE A 文案一致；不顯示目前面 badge。
- **A 面封面與文章庫：** 封面將每篇 `date` 記作發表事件；只有有效 `updated` 的 Asia/Taipei 日曆日與 `date` 不同時另記更新事件。每篇最多兩個事件，不保存中間版本歷史；熱力圖格數表示活動事件數，頁面另顯唯一文章總數與活動日期數，日期明細每列明標「發表／更新」。封面只顯示最新活動年份全年熱力圖，新年份自動成為封面年度，較舊事件仍可從文章庫找到其文章。預設選取最新活動日；點擊／鍵盤選取日期顯示當日全部事件連結。封面不顯示月份清單、摘要、標籤或篩選，並動態連到「查看全部 N 篇」。完整文章庫只含明確標記 `profile` 的公開文章，依發表日期新到舊，每篇一列、一個原 URL。單選標籤數動態依現有文章 tags 計算；標籤可重疊，不改 front matter、不推定面向。篩選寫入 `#tag=`，支援重新載入與瀏覽歷史；無 JS 時顯示完整列表且篩選控制隱藏。舊三路徑策展資料仍保留作內部驗證，但不再呈現為 UI。
- **A 面文字可讀性：** 保留 A 專用導覽使用繁中 UI sans stack、合宜字重與行高、圖示文字間距、足夠點擊列與 heading 留白；B 面與文章卡內容不在本次範圍。
- **搜尋與抽籤：** 搜尋共用一份公開索引，但依目前入口設定預設範圍，仍可切換到全部公開內容；B 面保留隨機抽籤。
- **文章身份：** A、B 或雙面只決定公開入口如何找到文章。一篇文章只有一份來源、一份正文、一個公開 URL 與一個 canonical；雙面文章由兩邊引用原路由。
- **成熟度提示：** 探索中文章可標示狀態、最近校準日與適用邊界；目前文章沒有 `thinking_status`，因此實際文章頁不會出現探索狀態塊。合成 fixture 已覆蓋此元件。
- **公開範圍：** 只有碎碎念沿用核准的 D／V 分流。其他文章、reading desk 學習資料及圖片都維持公開；A/B 不是隱私設定。圖片資產全數保留。

## 已知限制

- `/`、`/memory/` 與相容的 `/profile/` 都是公開入口；profile-only 文章的直接 URL 仍可公開讀取。A/B 篩選、未列在首頁或搜尋預設範圍，都不會讓資料變私人。
- 現有文章沒有 `thinking_status`，所以實頁不會顯示探索狀態塊；只以合成 fixture 測過該元件。
- 線上核心路由與重新載入已驗證；搜尋引擎收錄時間仍由外部服務決定，發布後的 CDN 節點也可能短暫保留舊快取。
- 圖片稽核確認資產存在、數量保留及引用可達；沒有逐張判斷圖片內容、人物／地點、授權、出處或 EXIF。
- 來源工作樹仍有大量未提交差異；GitHub Pages 產物有獨立部署提交 `fe09ac6d6`，不代表來源工作樹已提交。

## 暫停與回復方式

若暫時不想繼續，最安全的做法是暫停並保留現況，不做外部變更。請勿對整個工作樹執行 `git reset --hard`、整樹 checkout 或清理操作。若要撤回已做工作，只能依 [baseline](dual-surface-blog-baseline.md)、[進度紀錄](personal-navigation-progress.md) 和各階段報告確認檔案所有權，再逐檔處理本輪可分離的差異；若和既有修改重疊或無法辨識，就保留並先確認。`public/` 是建置輸出，可由專案 `verify` 流程重新產生，但該流程會 clean 並改寫 `public/`，執行前需確認此輸出改寫可接受。

未來再次部署前，仍須取得針對該候選的當次明確授權。部署後若要回復線上狀態，也需要另一次明確授權；本機回復不會回復 CDN 或線上服務。

本文件不假設固定 PID。若依上方命令啟動預覽，可在該 PowerShell 視窗按 Ctrl+C 停止；不要依舊紀錄終止其他程序。

失業的第N+7天, 當電商來敲門

發表於 2020-12-17 分類於 生活紀錄 文章字數： 2.9k 所需閱讀時間 ≈ 3 分鐘

當我接近一個工作面試的時候，他激起了我兩種感情。苛求要求自己，並期待自己可能成為適任的求職者。

「機會永遠是留給準備好的人」，先行者的耳提面命仍言猶在耳，然而這往往成為錯過機會的一種嘆息。原句「In the fields of observation, chance favours only the prepared mind」存在一個觀測領域的前提要點，因此應該帶入機率的概念。但儘管如此，當電商公司向我詢問有無面試意願的時候，這句話依然帶給我嚴重的打擊，我什麼都沒有準備好，破英文與各種半吊子做不全的領域，我該怎樣迎接這場面試？這場面試邀請只激起了我的恐慌與僥倖，恐懼著發揮不好，卻又僥倖地希望有機會能夠錄取。

我能否是一個為求目的，不擇手段的 Slytherin？

顯然成為Slytherin學院的學生，基本的血脈要求可能就源於他們先輩所累積的基礎，因此為求不知道是不是一個更偉大的利益，他們有諸多手段可以採取，或是從反面論述的角度來說，他們存在那種能夠運用各種手段來達成的需求，能夠服膺於那個要追求的目的，而這對於平日欠缺累積又一朝想要爬上枝頭的獾來說簡直天方夜譚。

自詡為Hufflepuff學院學生的我，一直認為努力與勤奮才是我所擁有的珍貴財富(雖然我也常常沒有成功完成)，然而面試跟第一輪測驗卻永遠不會給你這麼多時間，我先在兩天內寫了一個版本的英文履歷(還只是簡歷而且缺少自傳)寄給對方，再加上先前的線上考試，千辛萬苦總算是通過了第一輪測驗，而這部份對於分享面試經驗的大佬們而言僅僅算是開胃小菜，他們通常只用兩句話帶過這個部分。
隨後便接到了五天後前往公司面試的通知。我用盡了一些手段盡可能讓我自己能夠被錄取，首先我看熟了EXCEL中他所在意的整理邏輯(其實就是常見的樞紐分析以及資料整理，能夠從資料中了解目前對於公司有利與不利的資訊，像是這個月獲利最高的商品與相關資料)，還準備了大概十題左右的英文回答，例如說：你認為你的優缺點、請你說明你怎樣面對挫折這些，算是稍稍對一些英文面試有一個基礎的認識跟準備。然而最可怕的是這些盡善盡美的答案不只存在文法上的缺陷，是我總是背不完整，並且會突然呈現明顯的背書狀態，大概類似於雙眼無神陷入記憶漩渦，並試圖從中挖出我到底寫了些甚麼的痴呆感。
一直到面試前三天我才從中清醒，別妄想著透過一段一段詞藻堆砌出的錯誤英文能夠在面試中發揮順暢，我轉而以短句子應戰，卻一時忽略了我B級的英文聽力在整個面試過程中並無法幫助我順利接受任何訊息，或許就像那年的杏花微雨，從一開始便都是錯的。在整個準備的幾天，去除掉寫、練習的時間，我還需要花費一些心思讓我不至於從戰場上逃跑，即使逃避有用論在這年頭信仰者眾，也出了漫畫還搬上電視劇而捲起戀舞的風潮，但是否在我每次的逃避就已經註定了我再也無法接近某些機會？除了面對未曾接受過的英文面試恐懼，在這幾天的過程中我更清楚的意識到，過去那些我跳過的英文門檻與困難的拷問，由於我當初沒有及時把握，而換了一種方式應在我身上，阿~ 是來自於十年前的背後報復，一手背刺堪成出神入化，你這背骨仔！我小心翼翼地準備了三板斧，期待能夠被我猜到幾題，英文面試官你可敢應聲？(請想像西遊記太上老君的葫蘆)

害怕變成你心跳的聲音是甚麼樣的體驗？

害怕是整個過程中最深刻的情緒，心跳聲在我獨自一人的時候特別清晰，而害怕面試這件事情也幾乎跟心跳聲結合，你很難在這個階段下做事情，因為時間在這個階段忽快忽慢，醒來時恍若隔世，而準備時卻度秒如分。害怕讓我已經不能輕易的說我是因為面試機會難得而小心翼翼，仔細辯證的形容更像是因為誤會而被戴上勇者面具的懦夫，在一個不願意面對的怪獸前因為承諾而不能逃跑，卻又無可奈何。在這樣的情緒下我時時刻刻擔心著我在面試中發揮失常，但我也明知道我會表現失常，卻還是僥倖地希望有機會能夠錄取，面試完後我發現最可怕的敵人除了害怕之外，還有僥倖！

身體與心靈是分開算的，特別是在那些無法輕易面對的場合

熟讀動漫並中二如我，有時候喊個我要燃燒我的小宇宙，或是不會敗在同一個敵人之下是一件輕而一舉的事情，這些都時時刻刻強調了心靈力量的重要，而沒想到有一天我卻來個逆向操作，或許是打開方式錯誤，果然結果糟糕的一蹋糊塗。

誠如前面的心靈折磨，我已經失去了奮戰的動力，然而又因為僥倖與承諾而需要去出席搏一個全屍，而此時身體反而成為了我的倚靠，儘管我吃不好與睡不好，但「吐」這件事情卻讓我快速地擺脫身體的虛弱，通常在你緊張的時候這是一件非常好釋放壓力的一種途徑，雖然說它本身的存在或許就是壓力催生出來的強烈反應，然而經過它的釋放，身體似乎又能短暫的回歸巔峰，沒甚麼可以失去的身體能量而讓身體大概恢復到了無礙的程度，於是我一個大步流星的推開了這家電商的門準備迎接挑戰。

OH SO COOL~

每個人總有應對尷尬的口頭禪與方式，像我可能是以哇天啊這些驚嘆詞來掩飾我不知道該回甚麼的時刻(但你要相信我有時候是真的驚訝)，外國人面試官一直以頻繁的使用這個詞，他問了我對公司的了解與我的優缺點，或許是我的回答太破，我讓他只能口不擇言的說出他的OH SO COOL~

理所當然的我整場表現得非常差勁，甚至有點不忍直視，即使在中文面試官這邊有說明了一些關於我對於工作的看法、興趣以及相關經驗，也無法挽回那一聲聲OH SO COOL~所帶來的傷害。

喔是的，我在週五面試完，周一馬上就收到了所謂的感謝信，「非常感謝你投遞的履歷，由於一些公司的因素我們決定中止這些申請…」，因此我就雷聲大雨點小的結束了這場面試之旅，真的OH SO COOL~

關於operation職位

結合當初中文面試官與回家查的operation工作內容，我認為這個工作的重點在於資料整理，他並非是一個新潮的資料分析師，而更像是一個定時定量反饋目前資料狀況的營運類職位，並且更重要的工作內容在於串接各家廠商資訊與限時優惠，這是整個電商的運作核心，而心有餘力的話這個職位也會涉及到各式流程的優化，作為負責資料傳遞與整理的站點，是優化流程中必須在意的部分，即使他們公司描述這只是一個基礎職位。

不在沉默中爆發，就在沉默中滅亡

這次面試給我留下的深刻地警惕，也更使我明白關於害怕與緊張的界線，我不敢說類似的關卡能否再次難倒我，但我明白如果我再不把握住這次的警訊，那我大概又會陷入一個又一個的噩夢循環，歡迎來到輪迴地獄的概念。
最後這些跌跌撞撞的磨練期在近期算是意外告一個段落，我並不覺得我有從中成長，我只覺得我遇到了一個願意讓我先試著工作看看的研究助理，我目前的能力與經歷可能無法支撐我走到正職。我不知道先做一個計劃的專案助理一年是不是一個會後悔的決定？因為我仍然不是很確定我自己的目的是甚麼？我猜我喜歡分析，並告訴別人這些有趣的發現，但卻有點受不了中間過程中的各種嘗試與撞牆，我知道我現在可能要額外進修或者是確保我的工作內容在之後面試仍很有競爭力，但有學而不精不只是圖資的通病，也是我最困擾的問題，總結來說，我知道每個人對生活的選擇不一樣，但我仍缺少一個有力的答案，我心裡的聲音頂多只有到不排斥而已。嘆氣！

失業的第N+1天, 要說自己跟自己很熟超怪

發表於 2020-08-27 分類於 生活紀錄 文章字數： 855 所需閱讀時間 ≈ 1 分鐘

這是我失業的第N+1天，開始認為程式重要(再次認為)，開始覺得自己甚麼都用不好開始自我否定，開始爬文找點答案

勵志的找工作雞湯文，會說履歷別名自我推薦，他是給你工作的人認識你的途徑(除非你優秀到另外一個境界那我們另當別論)，可是要說自己跟自己很熟這點超怪，我甚至連該怎麼客觀的推銷自己都覺得害羞，如果說這迷惘了萬千求職者，我大概是撞的頭最嚴重的那個(沒有之一)，從科系就開始撞牆了(強調)！我連我要不要離開圖書館都不確定，或是說圖書館讓我離開的理由只有薪水跟考不上公務員(？)

對於圖書館外的工作我初步使用兩個判定標準
1.薪水
2.工作內容

可是…

趁著聚餐詢問了已經工作中的學長姊(同個學校同個指導老師)，除了那些題目上的差異之外，我聽說學長是特別做那個題目的，我卻只做了感興趣的部分，我發現我的求職計畫「極度」缺少規劃

我不太清楚我需要找甚麼樣的公司…
有沒有夢想進入甚麼樣的行業…

學長趁著取餐的空檔建議我，如果要走金融業，其實大可不必排斥資策會與他的小夥伴們，那其實算是一個證明，同學阿哲也做過類似的描述，不過他稍微鄙視之餘仍提出，確實那是一個讓你轉換跑道的手段，但成果看你的付出，不是保證班你要先有預期~

整理我目前履歷的問題源於沒有瞄準的對象，可能也生無大志

  1. 自傳
    使用時期撰寫的話，大學會明顯分掉注意力，使重點空泛，圖書館相關與研究所偏資料分析的重點會讓閱讀的人不明白重點在哪裡，至於性格與休課由於篇幅關係也都沒有點出與描述，雖然說
    →看似語意真誠實則缺少重點，(苦澀)
  2. 專長部分的描寫
    收穫應該是放在真的有機會面試(好難)的時候口頭說明
  3. 有規劃的話大公司真的可以嘗試看看，可是
    像是金融業有固定的招人時間，學長是建議大量投啦，但需要一份更精準的通用履歷，透過數次的面試你可以更準備你自己
  4. 最後一個，要考慮實習嗎？畢竟我還有一學期但是我要考慮到實習的地方是不是大公司，能不能成為我的履歷，這是重點(上次那個LINE有點可惜)
